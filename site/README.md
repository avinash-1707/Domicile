# domicile site

Marketing page for domicile, served at https://domicile.avnsh.me. Astro, one page plus a 404.

```sh
pnpm install
pnpm dev          # local preview
pnpm build        # static output in dist/
pnpm astro check  # type check
```

The hero cross-section in `src/components/Scene.astro` is SVG produced by a one-off generator script that is not kept in this repo. Small changes can be made in the SVG directly.
